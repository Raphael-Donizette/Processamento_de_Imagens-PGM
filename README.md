#  Processamento de Imagens PGM em C++

Repositório dedicado ao desenvolvimento de um sistema em **C++** focado na manipulação de matrizes bidimensionais de grande porte (`1024x1024`) para processamento de imagens digitais em tons de cinza no formato PGM (P2)[cite: 9]. Desenvolvido no âmbito das aulas práticas da faculdade.

---

##  Funcionalidades Implementadas
* **Leitura e Gravação:** Carregamento seguro e salvamento de arquivos de imagem PGM[cite: 9].
* **Ajuste de Brilho:** Modificação dinâmica dos pixels para clarear ou escurecer a imagem[cite: 9].
* **Binarização por Limiar (Thresholding):** Conversão da imagem em preto e branco com base em um limiar definido[cite: 9].
* **Transformações Geométricas:** 
  * Rotação para a esquerda e para a direita[cite: 9].
  * Espelhamento horizontal e vertical[cite: 9].
* **Filtros e Efeitos:**
  * Filtro passa-baixa (3x3) para suavização de ruídos[cite: 9].
  * Redução de escala (Iconização) para miniatura[cite: 9].
  * Escurecimento automático de bordas[cite: 9].
  * Efeito negativo[cite: 9].

---

##  Tecnologias Utilizadas
* **Linguagem:** C++
* **Concepção:** Manipulação de Matrizes Estáticas, Ponteiros, Funções, Modularização e manipulação de arquivos via `ifstream`/`ofstream`[cite: 9].
